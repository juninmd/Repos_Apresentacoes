# Repositórios de Apresentações

![Collection](https://img.shields.io/badge/Collection-Apresentações-blue.svg)

> Coleção de repositórios de slides e apresentações.

## Sobre

Este repositório agrupa materiais de apresentações técnicas sobre diversos temas, incluindo desenvolvimento híbrido, PWA, Rust, Azure, entre outros.

## Repositórios Inclusos

| Repositório | Tema |
|-------------|------|
| `apresentacao-desenvolvimento-hibrido/` | Desenvolvimento Híbrido (Ionic) |
| `apresentacao-global-azure-pwa/` | Global Azure + PWA |
| `apresentacao-pwa-api/` | API para PWA |
| `apresentacao-pwa/` | Progressive Web Apps |
| `apresentacao-rust-lang/` | Linguagem Rust |

## Formato

As apresentações estão em formato PowerPoint (`.pptx`) e/ou PDF, acompanhadas de código e recursos relacionados.
